# Sentiment Analysis Pipeline for E-Commerce Customer Insights

Led the end-to-end development of a natural language processing pipeline to analyze and classify customer sentiment from X (Twitter) posts related to e-commerce brands and products. Utilized Python frameworks such as TensorFlow and Scikit-learn alongside Apache Spark for scalable data processing and model training. Engineered both deep learning and classical machine learning models for text classification, information extraction, and sentiment polarity prediction.

Generated meaningful sentiment trend visualizations using Power BI to provide cross-functional teams with actionable insights, enhancing customer support strategies and improving conversational AI systems within digital commerce environments. This project highlights practical experience in NLP model development, text mining, and leveraging large-scale data for business impact.

Tools & Techniques: Python, TensorFlow, Scikit-learn, Apache Spark, NLP, sentiment analysis, text classification, Power BI, data visualization, scalable machine learning
