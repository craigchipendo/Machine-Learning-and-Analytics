# Machine Learning & Analytics Projects Repository

Welcome to a collection of diverse data science, machine learning, and analytics projects! This repository features real-world datasets, exploratory analyses, and model scripts designed for practical insight generation and skill building.

## Project Folders

- **Airline Satisfaction**
  - Predicts airline passenger satisfaction from survey data using multiple ML models (Random Forest, ANN, SVM, etc.).
  - Includes data cleaning, feature engineering, visualization, and benchmarking[1].
- **Claims Price Prediction**
  - Regression and analysis for insurance claim price estimation.
  - Jupyter workflows and documentation for replicability[2].
- **Clustering**
  - Unsupervised learning on media/streaming metadata (Netflix movies).
  - Explores TF-IDF text features, genre tokenization, and K-Means clustering[3].
- **Zimbabwe Mental Health Survey Dashboard**
  - Aggregates and visualizes Zimbabwe mental health survey results.
  - Dashboard highlights barriers, causes, demographic breakdowns, and financial aspects.

- **Twitter Sentiment Analysis**
  - Classifies tweets for positive/negative/neutral sentiment using NLP and scikit-learn pipelines.
  - Includes preprocessing, feature extraction, and accuracy scoring[4].
