# Machine Learning & Analytics Projects Repository

## Overview
Welcome to a collection of diverse data science, machine learning, and analytics projects. This repository showcases real-world datasets, exploratory analyses, dashboards, and model scripts designed for practical insight generation and skill building. 

## Project Folders

### Airline Satisfaction
- Predicts airline passenger satisfaction from survey data using multiple ML models (e.g., Random Forest, ANN, SVM). 
- Includes data cleaning, feature engineering, visualization, and model benchmarking workflows.

### Claims Price Prediction
- Regression modeling and exploratory analysis for insurance claim price estimation. 
- Provides Jupyter-based workflows and documentation to support experiment tracking and easy replication.

### Clustering
- Unsupervised learning project on media/streaming metadata (e.g., Netflix movies).
- Explores TF-IDF text features, genre tokenization, and K-Means clustering to group similar titles. 

### Zimbabwe Mental Health Survey Dashboard
- Aggregates and visualizes Zimbabwean mental health survey responses in an interactive dashboard. 
- Highlights perceived barriers, causes, demographic breakdowns, and financial aspects related to mental health access and outcomes.

### Crime Analysis Dashboard
- Tableau dashboard built on multi-country crime incident data (2021–2023), leveraging fact and lookup tables for crime types.  
- Visualizes yearly and monthly trends, geographic hotspots, crime-type distributions, and resolution performance with interactive filters for date, country, and status.

### Uber Ride Analytics
- R Markdown–driven analysis of the **Uber Ride Analytics Dataset 2024** from Kaggle, focusing on bookings, revenue, vehicle mix, and cancellations. 
- Produces ggplot2-based visuals and a polished infographic summarizing revenue realized vs. lost, payment-method revenue, vehicle performance, and cancellation patterns by hour and weekday.

### Twitter Sentiment Analysis
- Classifies tweets into positive, negative, and neutral sentiment using NLP and scikit-learn pipelines.   
- Includes preprocessing, feature extraction, model training, and accuracy evaluation for multiple classifiers.
